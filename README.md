# Fetch-YT-Data

A lean, cross-platform Python automation toolkit designed to stream YouTube content directly into **VLC Media Player** as a continuous network stream. 

**Zero bytes of video data ever hit your local storage—everything streams straight out of system memory.**

---

## 🚀 Features

* **Dual Streaming Engines:** Choose between automated multi-playlist bulk loading or an interactive on-demand console.
* **Private Feed Authorization:** Full compatibility with your localized browser cookies (`youtube_cookies.txt`) to easily access age-restricted or private tracks.
* **Custom Protocol Mapping:** Built-in protocol translation instantly converts custom link structures (`abcde://`) into clean, secure web formats (`https://`).
* **Zero Disk Overhead:** Bypasses downloading bulky container video files completely by grabbing direct stream links straight from Google media nodes.
* **Native Launchers:** Packed with instant execution shortcut scripts for Windows (`.bat`) and Unix-based (`.sh`) environments.

---

## 📂 Project Repository Structure

* **`fetch_YT_playlistData.py`**: The automatic stream coordinator. Aggregates multiple custom playlists (like **Watch Later** and **Liked Videos**), generates an `.m3u8` index map to bypass terminal line limits, and queues them in VLC.
* **`fetch_allVideos_Data.py`**: The interactive stream companion. Launches a live terminal loop prompt where you can paste **any standalone YouTube video or song link** on the fly for instant playback.
* **`youtube_cookies.txt`**: Your active authentication session profile token layout (Netscape standard format) required for locked arrays.
* **`vlc_stream_queue.m3u8.example`**: The short-lived virtual file playlist index handled automatically by the batch manager.
* **`requirements.txt`**: Declares mandatory runtime engine libraries (`yt-dlp`).
* **`run.bat`**: Double-click execution shortcut for Windows environments.
* **`launch_unix.sh`**: Fully sandboxed Virtual Environment (`.venv`) script automation pipeline for Linux and macOS.

## 🛠️ Prerequisites

Ensure your host machine has the following tools ready:

1. **Python 3.7+**
2. **VLC Media Player**
   * *Windows paths checked:* `C:\Program Files (x86)\VideoLAN\VLC\vlc.exe` or `C:\Program Files\VideoLAN\VLC\vlc.exe`.
   * *macOS standard path checked:* `/Applications/VLC.app/Contents/MacOS/VLC`
   * *Linux standard path checked:* `/usr/bin/vlc` (or distribution fallback binary mapping).

## 🔐 Handling Private Playlists & Session Cookies

To stream personal feeds like your private videos or **Watch Later** queue, `yt-dlp` needs localized browser verification parameters.

1. Install a browser extension that exports cookies in the **Netscape cookie format** (e.g., *Get cookies.txt LOCALLY* or *EditThisCookie*).
2. Log into your YouTube account in that browser profile.
3. Export your YouTube cookies using the extension.
4. Save the generated text data directly as **`youtube_cookies.txt`** in the root project folder.

### 📝 Required Cookie Format Reference
Your token array file must be standard Netscape formatting separated strictly by **Tab characters (`\t`)** instead of spacebars:

```text
# Netscape HTTP Cookie File
# This file is generated by yt-dlp.  Do not edit.

.youtube.com	TRUE	/	TRUE	[TIMESTAMP]	__Secure-3PAPISID	zsD4-xxx...
.youtube.com	TRUE	/	TRUE	[TIMESTAMP]	__Secure-3PSID		g.xxx...
.youtube.com	TRUE	/	FALSE	0		PREF			tz=UTC&hl=en
.youtube.com	TRUE	/	TRUE	[TIMESTAMP]	__Secure-1PSIDTS	sidts-xxx...
.youtube.com	TRUE	/	TRUE	[TIMESTAMP]	__Secure-3PSIDTS	sidts-xxx...
.youtube.com	TRUE	/	TRUE	[TIMESTAMP]	__Secure-3PSIDCC	xxx...
.youtube.com	TRUE	/	TRUE	[TIMESTAMP]	VISITOR_INFO1_LIVE	xxx...
```

## 🎮 How to Run

### Engine 1: Bulk Playlists Queue Aggregator
To bundle your configured lists together and queue them up automatically:
* **Windows:** Double-click **`run.bat`** or run `python fetch_YT_playlistData.py` in your terminal.
* **Linux & macOS:** Run `./launch_unix.sh` (ensure you run `chmod +x launch_unix.sh` once first).

### Engine 2: On-Demand Instant Stream Console
To open the real-time interactive playback engine and feed it standalone links dynamically:
```bash
python fetch_allVideos_Data.py
```
* **Tip:** Type `exit`, `quit`, or `q` anytime in the interactive loop to close down the shell audio engine and get right back to grinding chess!
